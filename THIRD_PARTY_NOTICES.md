# Third-party dependencies

The interface and original waveform icon contain no manufacturer/product branding. The source distribution contains application source, documentation, and tests; downloaded dependencies and manufacturer documents are excluded.

The runtime dependency is **pySerial 3.5**, installed by the package manager. Its copyright notices and BSD-3-Clause licensing remain intact. The Python runtime and Tcl/Tk are supplied by the user's Python installation and retain their notices. These technical names identify dependencies, not application branding.

- [Dependency source and license](https://github.com/pyserial/pyserial/blob/v3.5/LICENSE.txt)
- [Runtime license](https://docs.python.org/3/license.html)

If dependencies are later bundled in an executable, include their required license texts and notices. Do not remove dependency attribution to rebrand the application.
